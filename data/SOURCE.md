# 부산 관광 데이터 출처

한국관광공사의 국문 관광정보 서비스(TourAPI 4.0)에서 수집한 부산 지역 JSON을 사용합니다. 앱은 이 저장소의 JSON을 읽습니다. [공공데이터포털 원본 API](https://www.data.go.kr/data/15101578/openapi.do)

## 저장소에 포함된 JSON

| 파일 | `items` 건수 |
| --- | ---: |
| `부산_관광지.json` | 351 |
| `부산_레포츠.json` | 65 |
| `부산_문화시설.json` | 123 |
| `부산_쇼핑.json` | 986 |
| `부산_숙박.json` | 140 |
| `부산_여행코스.json` | 21 |
| `부산_축제공연행사.json` | 72 |
| **합계** | **1,758** |

`부산_여행코스.json`의 메타데이터 `total`은 22이며 실제 `items`는 21개입니다. 음식점(유형 코드 39) 원본 파일은 현재 저장소에 포함되어 있지 않습니다.

## 이용 조건

이 프로젝트는 수집 당시 기록한 공공누리 제3유형 기준에 따라 한국관광공사와 원본 API를 표시하고, 제공받은 JSON을 보존합니다. 공공데이터포털은 사진에 공공누리 제1유형과 제3유형이 함께 제공된다고 안내합니다. 사진을 재사용할 때는 개별 항목의 저작권 구분 코드(`cpyrhtDivCd`)와 원본 이용 조건을 확인합니다. [공공데이터포털 이용 안내](https://www.data.go.kr/data/15101578/openapi.do)
